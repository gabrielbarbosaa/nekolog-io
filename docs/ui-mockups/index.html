O que estas páginas são

HTML e CSS puros, sem build e sem rede. As cores vêm de tokens.css, que é cópia literal dos blocos :root e .dark do tema Grafite — um teste falha se as duas se separarem.

Nenhum botão funciona, nenhum campo envia. O que está aqui para ser aprovado é o desenho: o que cada tela mostra, onde, e com que palavra.

O tema claro e o escuro alternam no botão ◐, e a escolha fica salva no navegador.
